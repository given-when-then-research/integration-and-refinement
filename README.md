# Integration and Refinement

This module **integrates and refines** the datasets generated by the **exploration** and **exploitation** heuristics.
It merges both sources, compares overlapping entries, validates consistency, cleans redundant or invalid data, and produces a single unified dataset ready for evaluation.

---

## Pipeline Stages

The process runs through four sequential stages:

```
comparison → validation → cleaning → unification
```

Each stage generates an intermediate dataset stored in its own folder inside the `output` directory.

---

## Usage

Execute the main script:

```bash
python -B src/main.py ../dataset/exploration.json ../dataset/exploitation.json ./output

# or

make
```

* The first two arguments are the **input datasets** from the heuristic extraction stage.
* The third argument (`./output`) specifies the **output directory** for all generated files.

---

## Output Structure

After running the command, the following folders will be created in the `output` directory:

```
01_comparison/
02_validation/
03_cleaning/
04_final/
logs/
```

Each folder contains the dataset corresponding to its pipeline stage.
The **final stage** (`04_final/`) includes the **consolidated dataset** automatically named with a timestamp, for example:

```
consolidated_dataset_20251029_154345.json
```

This file is the **final unified dataset** produced by the integration and refinement process and should be used as input for the next step: *System Code Detection*.
